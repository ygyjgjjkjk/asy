# Тест «Ася» — готовый сайт

Сайт создан по файлу `Test_Turgenev_Asya.docx`.

## Что умеет
- 15 вопросов из исходного теста.
- В начале ученик вводит имя и фамилию.
- Один правильный вариант на каждый вопрос.
- Автоматический подсчёт: 15 баллов максимум.
- После завершения ученик видит свои баллы, процент и правильные/неправильные ответы.
- Ответы, ФИО, баллы и дата сохраняются на сервере в `data.json`.
- Для преподавателя есть личный раздел `/admin`.
- Из раздела преподавателя можно скачать результаты в CSV.

## Запуск на компьютере

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открой:
- Тест: http://localhost:3000
- Профиль преподавателя: http://localhost:3000/admin

Пароль по умолчанию:
`change-me-123`

Перед публикацией обязательно поменяй пароль через переменную окружения:

Linux/macOS:
```bash
ADMIN_PASSWORD="ТВОЙ_ПАРОЛЬ" npm start
```

Windows PowerShell:
```powershell
$env:ADMIN_PASSWORD="ТВОЙ_ПАРОЛЬ"
npm start
```

## Важно про «ответы приходят ко мне»

В этой версии результаты приходят в твой **личный профиль преподавателя на самом сайте**: `/admin`. Они сохраняются на сервере, поэтому после публикации сайта ученик отправляет работу, а ты открываешь `/admin` и видишь таблицу результатов.

Если тебе нужно, чтобы результаты дополнительно приходили именно в Telegram, WhatsApp, Gmail или Google Sheets, нужны соответствующие реквизиты/подключение сервиса. Архитектуру сайта можно расширить без переделки теста.

## Публикация

Проект можно разместить на любом Node.js-хостинге (например, Render/Railway/VPS). Для постоянного хранения `data.json` нужен persistent disk/volume либо внешняя база данных. Для реального школьного использования лучше подключить PostgreSQL/Supabase вместо JSON-файла.
